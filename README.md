# OpenCode Model Profiles

Choose agent models by name: set defaults once, then switch between profiles of concrete models per worktree.

Requires Node **22.18+**. Built for OpenCode **1.19.x**, starting at **1.19.0**.

This plugin is in early development and does not provide any commands yet.

## Install

Add the package to `plugin` in both `opencode.jsonc` and `tui.jsonc`:

```jsonc
{ "plugin": ["@lunchbox-labs/opencode-model-profiles"] }
```
